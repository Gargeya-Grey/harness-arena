# Foldaway Apartment

Use this recipe after changing the apartment reference, suite or browser inspector. Read `docs/foldaway-apartment.md` for the case contracts and the separation between delivery, behavior and visual quality.

1. Run `node --test tests/foldaway-apartment.test.mjs tests/foldaway-browser.test.mjs`. Source proofs cover the timeline; real Chromium exercises the visible controls, actual mesh bounds, interruption, reset and reduced motion. Browser absence is a skip, never rendering proof.
2. Run `node tools/foldaway-apartment/verify-reference.mjs --variant guided --out .cache/verify/<unique>/work/guided-reference`, then repeat with `--variant reversible` and a fresh output directory. The optional flag accepts guided, scrubbable or reversible; its default is reversible. It creates a fresh report with desktop, phone and interaction screenshots. Require every judged check to pass, and inspect screenshots for composition, readable furniture and clear stages. The reference is authored, never model performance evidence.
3. Run `node lab validate` and dry-run `experiments/foldaway-apartment-reversible-repaired-explicit-effort.yaml`. Require exactly three explicit high-effort configurations and one reversible case each. Native `workspace-tests@3` has dimension `format` and checks only delivery. The tiers remain untimed estimates.
4. Only with owner-authorized live calls, run the pilot or filter by harness. Keep the source frozen during the guarded run. Windows Codex uses installed-home context controls, with setup labelled partly kept out because global AGENTS.md remains. Retain errors and the exact run IDs.
5. Pass closed, ledger-matched runs to `node tools/visual-web/inspect.mjs --runs <ids> --out .cache/verify/<unique>/work/model-output`. The inspector reconstructs exact stored workspaces and refuses reports inside run stores. Inspect sample clearances and screenshots separately. Sampled axis-aligned bounds do not prove all continuous physical collisions impossible.
6. Preserve source/checker hashes, actual checks, visual judgments, omissions and shutdown status. Register task-generated evidence and a real observer handoff. Never delete model runs or prior evidence.

The repaired inspector samples guided movement and checks reversible retargeting atomically against actual group/mesh identities, matrices and bounds. All three public briefs set a 12-second completion maximum, so the inspector's 15-second completion guard has contractual slack. This differs from an operational transport/readiness guard. Version-2 blocked/incomplete observations have `passed: null` and are excluded from the judged denominator. A discrete conservative AABB sample still does not prove continuous collision freedom or aesthetic quality.
